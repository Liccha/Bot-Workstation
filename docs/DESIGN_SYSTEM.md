# Bot 工作站设计系统（锁定版）

## 定位

- 受众：机器人所有者与已授权管理员。
- 首要任务：先确认 SongBot / NapCat 是否就绪，再直接进入所需功能模块。
- 设计语气：明亮、轻盈、可信、紧凑；直接吸收 NapCat WebUI 的浅色主题、系统字体栈与信息层级，但不复制其品牌、人物和无关内容。
- 宏观结构：Side-rail Control Room。总览由服务状态双栏、两列命令矩阵和数据健康面板组成，不强加制作流程。

## 信息架构

1. 总览：展示服务状态、五个直接可用的模块入口和本机依赖健康度。
2. 歌曲信息：编辑 `song_data.db` 中已有歌曲元数据。
3. 谱面录入与图片设计：完整嵌入原 MczMaker，字体、波形、音频与模板坐标不改。
4. Stable 曲库：维护 Stable 工作簿并同步 CSV / SQLite。
5. 公告及网站管理：公告、附件和 teacharm.moe 网站文章。
6. 运营中心：仅保留每日歌曲、竞猜、Editor 正式站和 RM Stable 抓取；不重复 MCZ、Stable、公告入口。
7. 日志仅写入工作站 `logs/`，不占用导航或界面空间。
8. 手机端：四栏底部导航，提供总览、歌曲、Stable 与更多模块；手机直接编辑使用同一数据事务，复杂谱面编辑器由电脑端打开。

## 视觉系统

- 主表面：总览以近白为底，叠加位置不对称的淡蓝、淡粉和淡紫径向光场，形成参考界面的非均匀浅色层次；卡片保持近白，其他工作页使用同系列浅底纸。
- 强调色：樱花粉用于品牌标记、导航短色条、选中态、主按钮和焦点；成功、警告与错误色只表达状态。
- 字体：采用 NapCat WebUI 实际使用的系统 UI 思路，在 Java 中使用可自动覆盖中、英、日、韩的逻辑 `SansSerif`，由 Windows 映射至 Segoe UI / Microsoft YaHei UI 等系统字体。MczMaker 内部字体不受影响。
- 字号：正文 14，说明 13，分区标题 18，页面标题 28；不使用细体，层级由 Medium 字重、尺寸和留白共同建立。
- 圆角：按钮和输入控件 10，导航选中面 12，卡片 14；圆角与元素高度成比例，不使用大胶囊。
- 间距：4px 基准，常用 8 / 12 / 16 / 24 / 32。
- 边界：使用粉灰细边和表面明度差；导航仅用 4px 短色条确认当前位置，不使用贯穿整卡的装饰条或堆叠阴影。

## 交互与状态

- 导航采用同一套 2px 线性矢量图标，不依赖字体图标或 Emoji。
- 品牌标识使用随 EXE 一次性打包的 MczMaker 图标，运行时只从资源缓存读取，不访问外部图标路径。
- 选中态同时使用图标、背景和文字字重，不只依赖颜色。
- 服务状态显示“已启用 / 启用中 / 已停用”等明确文本，并保留状态点。
- 工具按钮按真实字体度量计算宽度，高度不低于 40px；只保留粉色主按钮和暖灰白次按钮两种视觉层级。输入框保持 40px；焦点不改变边框宽度，避免布局跳动。
- 模块切换使用 300ms 的透明度与 13px 下落入场，并尊重减少动态效果设置；不做循环装饰动效。
- 总览主区固定页头、内容可纵向滚动；不显示“核心服务 / 功能模块 / 环境与数据”分区文字，使用 20px 分组间距和卡片形态区分信息，提高密度。

## 安全不变量

- 管理员页面在授权前绝不构造。
- 首次密码验证后，由云端基于可信代理给出的客户端 IP 计算 HMAC 指纹并永久记录；前端不提交 IP。
- 云端只保存 IP 指纹，不保存原始 IP；密码仍只在本机校验，不上传。
- IP 信任服务不可用时回退为本机密码；验证成功的当前会话不受网络故障影响。
- 现有网页管理员设备白名单继续保留且不迁移、不清空。

## 不可变边界

- 不重写 MczMaker 的组件树、字体、字号、图片/日历模板坐标、Combo、音频或波形逻辑。
- 不修改 SongBot、Stable 和公告的数据路径及 ID。
- 不把 AccessKey、桌面令牌、管理员密码或原始 IP 写入前端、EXE 文本、日志或设计文件。
