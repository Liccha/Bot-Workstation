# 管理员权限模型

1. 工作站启动后默认锁定公告及网站管理，并先向云端查询“当前公网 IP 的 HMAC 指纹是否已受信任”。
2. 未受信任时，继续使用本机 `SongBot/admin_password.txt` 验证密码；密码不上传、不写日志。
3. 密码正确后当前进程立即获得管理员会话，同时云端基于 Vercel 注入的客户端 IP 计算 HMAC-SHA256 指纹并永久登记。工作站和浏览器都不能自行提交 IP。
4. 后续同一公网 IP 可直接解锁；云端不可达时安全回退到本机密码，不会因为网络故障错误放行。
5. 云存储只保存不可逆的 IP 指纹，不保存原始 IP。NAT、公网代理或运营商出口变化会改变识别结果，此时重新输入一次密码即可。
6. 管理员页面的构造函数必须接收由 `AdminGate` 私有签发的能力令牌；没有令牌无法创建页面或云端客户端。
7. 网站文章的读取、保存、删除和镜像同步在每次执行前重新验证该令牌。
8. 网页端原有管理员设备白名单继续保留；本工作站不会读取、重写或清空其设备 ID。
9. 云端公告、附件和网站文章接口仍在服务端检查 HttpOnly 管理员会话、历史白名单或桌面服务令牌。
10. 手机端默认不监听；用户在桌面明确启用后，8098 才在局域网开放。首次配对通过一次性六位码完成，单 IP 十分钟最多尝试五次；桌面随后为设备创建随机、可撤销且只保存哈希的隐藏账户。
11. 已配对设备可通过固定 HTTPS 云数据 API 跨网络使用。接口只接受歌曲、Stable、云状态和受控资源上传等白名单动作；电脑无需在线，本机管理端口也不暴露公网，管理员密码、AccessKey 和桌面服务令牌都不会发给手机。
12. 设备队列、响应和上传暂存路径均按设备 ID 隔离；资源票据按设备限速，工作站完成处理后删除暂存对象。管理员可随时撤销单个设备，紧急锁会阻断注册、提交、领取和完成等全部写操作。
13. 手机端可编辑普通歌曲和 Stable 元数据，但公告及网站管理只允许在已解锁的桌面会话中打开，不能用手机设备令牌绕过管理员能力令牌。

此模型防止工作站内的导航、快捷入口、直接页面构造、伪造转发头和普通 HTTP 请求绕过。可信 IP 不是唯一凭证：检查与登记端点还必须持有本机桌面服务令牌。拥有本机 Windows 账户控制权并能任意修改程序、密码文件、令牌文件或进程内存的人属于操作系统级威胁，不可能仅靠桌面 UI 彻底隔离，应由 Windows 账户权限和磁盘加密负责。
